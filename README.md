# 燃料电池质子膜 RUL 预测终端

面向质子交换膜燃料电池（PEMFC）耐久性分析的剩余寿命（RUL）预测工具。

输入电压/电流/温度等运行时间序列，输出退化趋势拟合、剩余寿命预测与健康状态评估，支持 CSV / TSV / Excel 多文件接续合并。详细使用方法见 [`使用说明.md`](使用说明.md)。

## 快速开始

```bash
pip install -r requirements.txt
python -m streamlit run app.py    # 启动图形界面
# 或
python rul_pipeline.py            # 命令行流程
```

Windows 下可直接双击 `启动终端.bat`。

## 目录结构

| 路径 | 说明 |
| --- | --- |
| `app.py` | Streamlit 图形界面与交互逻辑 |
| `rul_pipeline.py` | 核心预测流水线（数据读取、退化建模、RUL 估计） |
| `models_terminal.py` | 终端入口与命令行参数 |
| `train_terminal_model.py` | 模型训练脚本 |
| `data_memory.py` | 数据集缓存与特征记忆库 |
| `live_canvas.py` | 实时曲线绘制 |
| `*.ipynb` | 阶段性实验记录（GRU / LSTM / 物理约束 / 多尺度） |
| `模型库/` | 训练得到的模型权重与版本对比结果 |
| `数据记忆库/` | 历史实验的输入特征与趋势数据 |
| `输出/` | 运行输出（已 gitignore，不入库） |
